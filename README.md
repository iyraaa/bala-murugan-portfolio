# Bala Murugan HR Portfolio

A responsive personal portfolio website inspired by the reference layout, redesigned for an HR professional.

## Files
- index.html
- style.css
- script.js
- bala-profile.jpg

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the folder to a GitHub repository and import it into Vercel or Render as a static site.

No backend is required. The contact form opens the visitor's email app using a mailto link.
